CREATIVE BRAINSTORMING SKILL

/BRAINSTORM

An Agent Skill for Claude, built on theater improv and ADHD. It quickly stacks half a dozen ideas on each other with "Yes, and..." energy: focused, fast, and a little weird, like brainstorming with the most creative friends you know.

Download brainstorm.skill Install in 60 seconds

What it does

Brainstorm with creative entrepreneurs

Every session is like a call with the sharpest founders you know, riffing until something buildable falls out. Ideas build on ideas, and the energy stays confident and forward-moving all the way through.

You get 5-6 real ideas each time. Give feedback and it goes deeper, with more control. Every idea is already road-tested to push to the best buildable version of your goal.

How it does it

We Synthesized ADHD

Drawing on years of experience as a founder and executive coach, this skill deconstructs the way entrepreneurs brainstorm: fast, associative, optimistic, unwilling to stay in one lane. "Yes, and..." keeps every idea building on the last instead of resetting; pulling concepts from unrelated industries simulates subconscious free-association, the same way you come up with great ideas in the shower.

Under the hood, Claude is doing its thing, researching and pressure-testing every idea, so what reaches you has already passed the first technical hurdles.

Setup

Easy as 1, 2, 3

  1. 1
    Download brainstorm.skill from the button above, or clone this repo and zip the brainstorm/ folder yourself.
  2. 2
    In Claude, open Settings → Capabilities/Features → Skills and upload the file.
  3. 3
    Toggle the skill on. (This requires Code Execution to be enabled; Claude will tell you if it isn't.)

All set! Type /brainstorm <your goal> in any chat. (If you don't give it a goal, the Skill will read the conversation and make a guess.)

No intros, no upsells, no hooks to keep you engaged. Just a genius-level creative brainstorming partner that's always in your corner.
